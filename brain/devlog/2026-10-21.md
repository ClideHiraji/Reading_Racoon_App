# 2026-10-21

## Done
- **Hub wireframes:** three rounds on the design canvas ("Reading Racoon Home Hub Wireframes"): big cards → tap spots around a scene → a portrait game lobby modelled on the user's Mobile Legends screenshots, plus a diamond Play picker. The user approved the lobby and picker.
- **Built the home hub in Godot** ([[D-015 Home hub and Adventure-only time locks]]): `scenes/hub/hub.tscn` with Racoon on a banig mat in the middle, profile/level/coins/XP/saved-cloud on top, Shop and Today on the left, a hideable "For you" panel on the right, Closet/Stickers/Words tabs, and a glowing slanted gold PLAY button with the world crest. New drawn controls: `PlayButton`, `DiamondTile`, `BanigMat`.
- **Play picker** (`scenes/hub/play_picker.tscn`): Adventure as the big gold diamond with the current world; Library, Practice, Watch & Listen and Big Test around it; locked tiles grey with a lock, and Racoon says when they open. A footer shows free play left.
- **Adventure-only time locks:** `AccessPolicy.hub()` (asleep 9 PM–6 AM only), `free_play()` (45 min/day shared outside Reading time), `adventure_opens()` ("opens at 7:30 AM"). `GameState.open_section(id)` applies each section's rule (`HubSections`); a closed Adventure sends the child back to the hub with Racoon explaining. Usage events also carry `free_minutes`.
- **Routing:** start screen and login → hub; after the pre/post-test → hub; Home button on the path; Closet Back → hub. Unbuilt sections open a "Racoon is still building it" page.
- Tests: 3,372 unit checks (new hub/free-play/opening-time rules, every hub section has an icon, a rule and a real scene) and the UI smoke test (hub → picker → path → hub, coming-soon page, closet from the hub, Adventure closed in class hours, free-play timer used up, lock at night) pass. `tests/hub_shots.gd` screenshots both time states.
- The dashboard session finished PR #2's title and description; 114 backend tests pass; not merged yet.

- **New colors** ([[D-016 Thesis color palette]]): the user's (and the thesis's) light blue, cream, yellow and orange across the whole game, dark brown text on every colored button, leaf green and the world accents kept. `Palette.text_on()` and `Palette.readable()` keep text at WCAG 4.5:1; scene files and the theme updated; the user's hidden sunburst on the hub kept. 3,395 unit checks and the UI smoke test pass; screenshots of the hub, picker, start screen, lesson, results and shop checked.

- **Every hub section built** ([[D-017 Practice Library Watch and collections]]): six Practice games (Rhyme Pop, Memory Match, Spin the Words, Syllable Train, Story Shuffle, Word Catch) on Adventure's own content, no BKT; a Library of 8 placeholder picture books (English, Filipino, Bisaya) with a read-along reader that lights each word, two questions and a sticker; Watch & Listen with 4 songs and chants and 3 read-alongs, plus a player for teacher videos once downloaded; a 40-sticker album, My Word Book with "Practice my words", and Today's three goals with the days played. Lessons now add words, a daily sticker and the lesson goal.
- Shared UI: `Kit`, `ReadAlong`, `Balloon`; `Collection`, `PracticePool`, `MediaLibrary` in `scripts/core/`. Speech reports word boundaries and falls back to a Filipino voice for Bisaya.
- Tests: 3,827 unit checks (stickers, goals, words from items, game locks, every book and song) and the UI smoke test now plays each game, reads a whole book, finishes a song and opens the album, word book and Today. `tests/section_shots.gd` screenshots every new screen.
- Asked the dashboard session to accept the six new event types (practice, book, media, sticker, word, goal).
- **Teacher content download** ([[D-020 Teacher content download in the game]]): `Sync` fetches the dashboard's content manifest (ETag/304), saves teacher books and videos into `user://content/`, downloads page pictures and videos one at a time to `.part`, checks SHA-256 on a worker, then moves them into place; Wi-Fi only (Android metered check), never during a lesson (a lesson cancels a download), removed items' files deleted. `ContentPlan` refuses any path outside `user://content/`. The reader and Library show teacher page pictures. Checked end to end against the local server (`tests/content_e2e.gd`): mobile data, Wi-Fi, 304, tampered file, removed video; the test content was deleted afterwards. 3,849 unit checks and the UI smoke test pass.
- Opened the teacher dashboard and the hidden admin portal for the user: ran the dashboard migrations and the demo seed on the empty local DB, set a local `ADMIN_PATH`, served the dashboard branch on port 8010. The dashboard session later replaced that `ADMIN_PATH` with a new secret that never appeared in a chat (the first one had); read it from the worktree's `backend/.env`.
- Committed and pushed the hub, palette, sections and content download (e39f4d9, 93b147b, fd70b17); the first commit removes old Unity `.gitignore` patterns that hid `scenes/library/`.
