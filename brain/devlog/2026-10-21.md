# 2026-10-21

## Done
- **Gemini teacher report** ([[D-018 Gemini teacher report]], issue 23, FR-05, FR-21) on branch `claude/wizardly-morse-a5a2cf` (built on the teacher dashboard branch, b07e0af):
  - Gemini writes the report's two paragraphs; the strengths, needs, activities and sub-skill table stay rule-based (`TemplateReportWriter::classify` gives the AI the same split).
  - `WriteAiReport` job, queued 10 minutes after a sync that stored new events (unique per learner, so one report per play session), or when a teacher opens a report with no AI version for the current numbers. `ai_reports` keeps one row per set of numbers.
  - Prompt `report-v1`: temperature 0.3, student code + numbers only, no names, ages or dates. **Consented learners only.**
  - `AiReportCheck`: two plain paragraphs, 40–180 words, no other learner's code, every number found in the facts, every needs-support sub-skill named. Up to 3 calls (timeouts, 429, 5xx and refused text retried; a bad key isn't), then the template and an `ai.report_fallback` system log entry.
  - `ai_logs` for every call (input JSON, reply, status, reason, latency, tokens) and an **AI calls** tab in the admin logs; the privacy audit lists both AI tables and says who is sent.
  - `php artisan report:write <code>` checks the key without playing. The report footer says whether the template or the AI wrote the paragraphs.
- Tests: **139 pass on PostgreSQL 18.6** (25 new, Gemini faked with `Http::fake`). `phpunit.xml` forces `LLM_API_KEY` empty so tests never use a real key.
