# 2026-10-21

## Done: backend for the hub sections
- `/api/sync` accepts the six hub event types the game now sends (`practice`, `book`, `media`, `sticker`, `word`, `goal`, game D-017). They are stored only; Practice and reading never change BKT, coins or the level. A feature test checks each is acknowledged.
- The section schedule gained `free_play_minutes` (45), `day_start` (06:00) and `day_end` (21:00) for the game's hub and free play (game D-015): new columns, config defaults, teacher schedule page fields and validation, and `GET /api/access/student/status` sends them. The server now answers `sleeping` at night, like the game. Noted in [[D-014 Time-restricted access rules]].
- Fixed Graphify's review finding on PR #2 (a sync could log an event another concurrent sync stored); PR #2 has its title and description.

## Next
- Show the new hub activity (books read, practice games, stickers, words) on the teacher's student page.
- A teacher screen to pick Library books and Watch & Listen videos, and an endpoint that sends `library.json`/`watch.json` (game D-017).
- Count `free_minutes` on the server if the teacher dashboard should show free-play time.

## Done: Library & Videos for teachers
- Teachers add openly licensed books (pages, pictures, key words, two picture questions) and Ogg videos on a new **Library & Videos** page, assign them to their sections and publish them; the admin portal's Content page lists everything and can unpublish ([[D-019 Teacher content manifest]]).
- `GET /api/content/manifest` sends a section's published items in the game's `library.json`/`watch.json` shapes with a version/ETag; `GET /api/content/files/{id}` streams videos and page pictures with their SHA-256. Files are private, named by uuid.
- Tests: 9 new (licence and pictures required, game shape, section scoping, drafts hidden, ETag 304, Ogg-only and size cap, auth and 404s, picture moves on edit, files removed on delete, admin unpublish).
