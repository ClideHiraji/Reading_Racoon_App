## Learned
- The server stores sync payloads as sent and only checks the event type, so new fields (retry, hint) need no server change; new event *types* would.
- Opening the hub on a fresh profile queues the day's first sticker, so "no new events" checks must look at event types.
- A new `class_name` needs `--import` before headless tests can see it ([[Godot headless tests need an import first]]).
- Godot drops SVG animation, so animated art must be rendered to frames ([[Godot cannot play animated SVG]]).
- `%Name` needs the node to be owned by the scene; nodes built in code need `owner = self` ([[Code-built unique nodes need an owner]]).
- A window taller than the screen is clamped, which changes the layout in screenshots; shoot at 576×1024, the same 9:16 shape.
- Godot buttons pin the icon to the edge; ChunkyButton now draws it beside the text ([[Godot buttons pin the icon to the edge]]). `get_meta(key, null)` errors on a missing key; check `has_meta` first.
