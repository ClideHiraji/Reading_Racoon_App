## Learned
- In Blender, painting markings onto mesh faces gives stair-step edges. A smooth, anti-aliased texture projected from the front (made with numpy inside Blender) keeps them as clean as the 2D drawing. An inside-out shell with backface culling gives the toon ink outline.
- Godot 4.7 rasterises the redesigned Racoon's SVG faithfully at runtime (`Image.load_svg_from_string`), gradients included, in 4–6 ms on a laptop. That's fast enough to draw his parts at their real size and stay sharp.
- A notch tested on a 16:9 screen looks worse than any real phone: notched phones are about 19.5:9, so the canvas gets taller and the middle of Home has room. Simulate notches at a real phone's shape.
- `tests/ui_shots.gd` hangs (it calls the removed `lesson._on_continue()`); the other shot scripts cover its screens.
- Blender switches Rendered shading back to Solid whenever it loads a file. Material Preview lit only by the scene's lights is kept and shows the same EEVEE toon look. [[Blender opens files in Solid shading]]
- A flat 2D character built from round shapes can turn all the way around: give each part of the drawing a place on the round head or body, and move it with the turn. [[Turn a flat 2D character by putting its parts on round shapes]]
- Headless Chrome with `--virtual-time-budget` fires timers but runs only one animation frame, so testing an animated page needs a clock the page steps itself. [[Headless Chrome runs animation frames only once]]
- The canvas's board runtime renders every text placeholder as an HTML span, which SVG `<text>` can't show. Live text over SVG goes in an HTML layer.
- A 3D model can be scored against its 2D drawing when both are rendered in one frame (1 Blender unit = 100 drawing px, an orthographic camera). Silhouette overlap and landmark offsets made each round measurable; headless Chrome needs `--disable-gpu` for a reference that's the same on every run. [[Compare 3D renders with 2D art in one shared frame]]
