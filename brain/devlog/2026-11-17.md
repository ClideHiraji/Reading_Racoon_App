## Learned
- Decide an arm's layer from where its paw is, not only from which way he's turned. Test only the paw end, as wide as the arm, so the root by the shoulder doesn't drag the whole arm in front of his jaw ([[Turn a flat 2D character by putting its parts on round shapes]]).
- [[Record coded tweens as AnimationPlayer keyframes]]: run the move's script on a pretend clock and write each tween as keys. Use `deterministic` and a RESET animation so interrupted moves settle back to rest.
- [[Windows text-to-speech blocks when it stops]]: stopping the system voice mid-line freezes Godot for ~210 ms on Windows; never interrupt, hand it a sentence at a time. Also: one file open per burst of writes, bulk theme overrides, threaded scene loading.

- [[Pack a Godot puppet's SVG parts onto one sheet]]: one import instead of one per part. UVs come from each part's rectangle on the sheet, and a shader mask needs its sub-rectangle and an outside-the-box test.
- Before a move that walks or jumps, read its keys for how far it goes, and scale it to the box that clips the character. Ease the change over the blend so an interrupted walk doesn't jump.

- [[A saved Godot scene keeps a sheet's old UVs]]: after repacking a texture sheet, a scene saved before it still shows the old rectangles unless the script resets them on load.
- Rank cosmetics for children by look and effort, never by chance. Fixed prices, goals shown up front, and earned items that count reading.
