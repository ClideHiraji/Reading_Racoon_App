## Learned
- `draw_colored_polygon` draws nothing, only an "Invalid polygon data, triangulation failed" error, when its outline crosses itself. Check a hand-typed outline with `Geometry2D.triangulate_polygon`: an empty result means it crosses.
- A Transform2D built from two points (x axis between them, y axis straight down) shears when the points tilt; for a stiff object, build y perpendicular to x.
- [[Windows text-to-speech blocks when it stops]] (updated): only the stop can go on a worker thread; starting a line from quiet costs a 130–175 ms frame inside Godot.
- [[Judge new art inside the game, not on a board]]: read the art direction's rejected looks first, and show new art on real game screens at real sizes before asking for a choice.
- Godot's SVG import draws user-space gradients, clip paths, even-odd fills and dashed strokes, so a full-colour icon set needs no raster art.
- A shape union with one outline: draw every part with a stroke twice the outline's width, then every part's fill on top.
- A handler that waits on `get_tree()` must check `is_inside_tree()` first when its signal can come after the screen has gone (a cut voice finishing, for one).
- Hunting unused assets: search scene files (`ext_resource` paths and uids) as well as scripts, and remember paths built at runtime (`get_basename() + "_bake.res"`, the rig's sheet names). Then prove it by running the game without them.
- Unit tests run in `_init()`, before the autoloads exist, so a test that loads a game script using `GameState` fails to compile there.
- A script edited on Windows can have CRLF line ends (`kit.gd`, `lesson_complete.gd`, `ui_smoke.gd` here): a patch script must match them, and a rerun must skip edits already made, or it inserts them again.
- `Speech.say(text)` with no language now means the buddy's language (D-033): content must always pass its own language, or the Filipino voice reads English words.
