## Learned
- [[Vet the ref a plugin marketplace installs]]: skillsmith installs GodotPrompter from `plugin-bundle`, not `master`. Git Bash rewrites sparse-checkout paths that start with `/`.
- `composer audit` finds **9 advisories in 6 backend packages**: `laravel/framework` 12.70.0 (fixed in 12.71.0), and `symfony/http-foundation`, `http-kernel`, `mime`, `routing` and `yaml` 7.4.19–7.4.21 (fixed in 7.4.22–7.4.23). One concerns trusted proxies, which matters once Cloudflare or another proxy sits in front.
- `bootstrap/app.php` trusts no proxies. Behind Cloudflare, `$request->ip()` would be Cloudflare's address, so the login limit (60 a minute per IP) would lump schools together.
