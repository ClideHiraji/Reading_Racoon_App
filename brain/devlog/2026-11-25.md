## Learned
- **To make a form work in place without a second source of truth,** fetch the POST, let it follow the redirect, and read the flash message and counts from the returned HTML (`DOMParser`). The server code doesn't change, and the plain form post stays the fallback.
- **A table cell hidden on wide screens must be the row's last cell.** A `display: none` cell earlier in the row shifts every later column.
- **`:first-child` counts as a class in specificity.** So `.roster td:first-child` (0,2,1) beats `table.table-cards > tbody > tr > td` (0,1,4); scope the phone rules with the table's own class.
- **Delegate click handlers for links inside a part that can be swapped,** or they silently stop working after the swap.
