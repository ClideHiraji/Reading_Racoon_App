# BKT passes 0.95 after 3 correct answers

With the thesis's starting parameters (Table 3.5), three correct answers in a row push P(L) past 0.95 for **every** sub-skill:

| Sub-skill | After 1 / 2 / 3 correct | After 1 wrong at the start |
|---|---|---|
| Phonological awareness | 0.53 / 0.87 / 0.97 | 0.03 |
| Phonics | 0.60 / 0.90 / 0.98 | 0.04 |
| Vocabulary | 0.60 / 0.88 / 0.97 | 0.06 |
| Reading fluency | 0.52 / 0.89 / 0.98 | 0.02 |
| Literal comprehension | 0.53 / 0.87 / 0.97 | 0.03 |

**So:** never treat a single P(L) crossing as proof of mastery. Require a minimum number of attempts (we use 5), and set the guess rate to match the number of choices (3 choices ≈ 0.33, not 0.20).
