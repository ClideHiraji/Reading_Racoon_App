# A Gemini subscription doesn't include an API key, but it includes Cloud credits

- The Gemini app subscription (Google AI Pro) can't be used by a backend directly.
- Since January 2026, AI Pro includes about **US$10/month in Google Cloud credits**. Apply them to a billing-enabled Cloud project, and they pay for Gemini API calls. They reportedly expire after a year.
- Use the paid (billing-enabled) terms. Under the free tier's terms, prompts may be used to improve Google's products, which isn't acceptable for children's data.
- Check the exact credit amount and model prices on Google's own pages before quoting them in the thesis.
