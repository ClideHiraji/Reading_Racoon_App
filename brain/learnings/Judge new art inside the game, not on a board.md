# Judge new art inside the game, not on a board

The first redrawn pictures (glossy stickers: gradients, shine, coloured outlines, a ground shadow) looked right on the canvas board: white panel, cream cards, a leafy background like the user's reference. In the game they looked out of place: the game is flat cut paper (D-009), and its buttons, cards and scenery have no shine and no outlines.

- **Before drawing a new set, read the art direction's "Rejected" list.** D-009 had already rejected "bold sticker" and "soft clay" looks; the first set was both.
- **Show new art on real game screens before asking for a choice.** Use screenshots of the screens it goes into (Home tiles, Practice, a lesson card, the sticker album) at the sizes it ships at, not a gallery board. A reference picture sets the mood; the game's own world sets the rules.
- **Keep the drawing in code with a style switch.** One `mode` (`paper`, `soft`, `ink`) redrew all 60 pictures in minutes, so the fix cost a style function, not 60 drawings.
