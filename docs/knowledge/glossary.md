# Glossary

| Term | Meaning |
|---|---|
| **AGAP.AI** | DepEd project (Jan 2026), Accelerating Governance and Adaptive Pedagogy through AI |
| **ARAL** | Academic Recovery and Accessible Learning Program (RA 12028). **ARAL Basic** = non-readers, **ARAL Plus** = emerging readers |
| **BKT** | Bayesian Knowledge Tracing: probabilistic mastery model with P(L₀), P(T), P(G), P(S) |
| **P(Lt)** | Current probability that the student has mastered a sub-skill |
| **CRLA** | Comprehensive Rapid Literacy Assessment |
| **CVC / CVCC / CVVC** | Consonant-vowel word patterns used in phonics (e.g., *cat*) |
| **DBR** | Design-Based Research |
| **E-CAIR** | DepEd Education Center for AI Research |
| **EDCOM II** | Second Congressional Commission on Education |
| **EGRA** | Early Grade Reading Assessment |
| **EM** | Expectation-Maximization: used to re-fit BKT parameters from data |
| **Flow Theory** | Csikszentmihalyi: deep engagement when challenge matches skill |
| **GBL** | Game-Based Learning |
| **Heart Recovery** | Low-stakes mini-game triggered after 3 consecutive errors; restores hearts |
| **IPO** | Input–Process–Output conceptual framework |
| **LRL** | Language and Reading & Literacy (MATATAG domain) |
| **MATATAG** | DepEd K-10 curriculum (SY 2024–25): MAke curriculum relevant, TAke steps to accelerate facilities, TAke care of learners, Give support to teachers |
| **MLDLC** | Machine Learning Development Life Cycle (6 stages) |
| **Phil-IRI** | Philippine Informal Reading Inventory |
| **PU / PEOU** | Perceived Usefulness / Perceived Ease of Use (TAM constructs) |
| **RA 10173** | Data Privacy Act of 2012 (Philippines) |
| **SiKaP / GMRC** | Grade 1 subjects (Sibika at Kultura/Pagpapakatao; Good Manners and Right Conduct) |
| **Stealth assessment** | Assessment embedded invisibly in gameplay |
| **TAM-C** | Combined Technology Acceptance Model |
| **WM** | Weighted mean = Σ(scale × frequency) / N |
| **ZPD** | Vygotsky's Zone of Proximal Development |
