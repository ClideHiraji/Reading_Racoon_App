# Pictures (full colour)

The game's pictures for words, stickers, Home tiles and Practice games (D-027). They are cut from
paper like the rest of the game (D-009): flat colours from the palette, each piece lifted on a crisp
little shadow, no shine or outlines. Faces go on animals, the sky and fruit. They are drawn in their
own colours and never tinted.

They were drawn for Reading Racoon by `tools/icon-art` (`python icon_set.py <this folder>`), so they
need no credit. Change a picture there and run it again, not here.

The one-colour glyphs that the game tints (on buttons, badges, tabs and the path) stay in
`assets/icons/`, from game-icons.net (CC BY 3.0).
