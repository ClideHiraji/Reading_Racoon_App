# The team's animations (references)

The animated SVG exports the team made of the earned star and the two hearts. The game doesn't load
them: it plays the same animations from the team's Lottie files in `assets/anim/lottie/` (D-022),
because Godot can't play animated SVG. They're kept here, outside the game, as references.

Confirm their source and license before release (see `assets/icons/CREDITS.md`).
